# Dem 配置项参考文档

|容器属性|值（容器）|
|---|---|
|名称|Dem|
|描述|Configuration of the Dem (Diagnostic Event Manager) module.|
|描述|概述：Dem（Diagnostic Event Manager）是AUTOSAR中负责管理诊断事件的模块，它记录和报告故障码（DTCs），并支持故障诊断的相关过程。|
|描述|注意：在配置Dem时，需确保故障码的唯一性和与ISO 14229标准的一致性；配置参数应满足项目的诊断策略要求；在多ECU系统中，还需考虑故障码的系统级一致性和网络管理需求。|
|多实例个数|0 - 1|

## 1. DemConfigSet

|容器属性|值（容器）|
|---|---|
|名称|DemConfigSet|
|描述|This container contains the configuration parameters and sub containers of the Dem module supporting multiple configuration sets.|
|描述|概述：DemConfigSet 是用于定义诊断事件管理（Diagnostic Event Manager）模块中所有配置集的容器，它包含了用于车辆诊断的所有配置参数。|
|描述|注意：在AUTOSAR CP 4.4中，每个DemConfigSet必须唯一且对应于特定的诊断需求；配置集应包含所有必要的诊断事件、操作周期和存储条件；在多配置集系统中，需确保正确的配置集被激活以匹配当前的车辆操作模式。|
|多实例个数|1 - 1|

### 1.1. DemComponent

|容器属性|值（容器）|
|---|---|
|名称|DemComponent|
|描述|This container configures the monitored components and system dependencies.|
|描述|概述：DemComponent配置项用于定义诊断事件管理（Diagnostic Event Manager）中的组件，它将特定的诊断事件与软件组件关联起来，以便于对故障进行分组和管理。|
|描述|注意：在配置DemComponent时，需要确保每个诊断事件只关联到一个组件，以避免管理上的混淆；组件的命名应当遵循项目规范，以便于识别和维护；在AUTOSAR CP 4.4标准中，DemComponent的属性和结构应符合规范定义，任何偏离都需要特别注意并进行调整。|
|多实例个数|0 - inf|

|配置项属性|值（布尔参数配置项）|
|---|---|
|名称|DemComponentIgnoresPriority|
|描述|This configuration switch defines, whether the priority of events at this component shall be ignored.|
|描述|概述：DemComponentIgnoresPriority 是一个配置项，用于指定诊断事件管理（DEM）组件是否忽略事件的优先级设置，这可能影响事件的处理和存储。|
|描述|注意：在AUTOSAR CP 4.4标准中，通常事件的优先级是由系统设计者根据诊断需求来设定的；如果设置了DemComponentIgnoresPriority为true，则意味着所有事件将被视为同等优先级，这可能会导致高优先级事件得不到应有的快速响应；在配置此项时，应仔细考虑系统的诊断策略和实际需求，以避免潜在的问题。|
